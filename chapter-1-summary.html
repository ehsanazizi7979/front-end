01 · The big picture

JavaScript is a language and an ecosystem

The chapter frames JavaScript as a widely deployed, high-level, dynamic language that supports both object-oriented and functional styles.

Its syntax has some historical resemblance to Java, but JavaScript is a distinct language. ECMAScript (often shortened to ES) is the standards name for the language; “JavaScript” is the familiar name used in everyday development. The standards evolve over time, and modern JavaScript includes features such as modules, classes, promises, and async functions.

Core distinction: JavaScript defines the language; the host environment supplies capabilities around it. Browser APIs and Node.js APIs are not the same thing as the core language.
02 · Runtimes

One language, different host environments

A browser makes JavaScript useful for interactive pages, user events, and network requests. Node.js provides a runtime outside the browser, commonly used for servers and command-line tools. Code that depends on a host API is tied to that environment, even though the underlying language is JavaScript in both places.

03 · First steps

Experiment in a console

The chapter encourages trying short expressions in a browser’s developer console or in Node’s interactive REPL. This quick feedback loop is useful for learning expressions and inspecting results.

// Original example: evaluate a few expressions
const width = 8;
const height = 5;
width * height;                 // 40
(width === 8) && (height > 0); // true

For a browser page, a minimal script can run from an HTML document. The example below is original and self-contained:

<script>
  const message = "Hello, JavaScript!";
  document.querySelector("#greeting").textContent = message;
</script>

In browser code, the document object comes from the browser host, not from the core language itself.

04 · Guided tour

The chapter’s quick tour of the language

Rather than teach every detail, Chapter 1 previews foundational building blocks that later chapters explore carefully:

Values and variables

Numbers, strings, booleans, nullish values, arrays, and objects can be stored and passed around. Variables are declared with let or const.

Expressions and operators

Arithmetic, comparisons, and logical operators combine values into new results. Prefer strict equality (===) for comparisons.

Statements and control flow

Conditionals and loops choose or repeat actions. Blocks group statements and make control flow easier to read.

Functions

Functions package reusable behavior, accept parameters, and may return values. They are also values, enabling flexible functional patterns.

Objects and arrays

Objects organize named properties; arrays represent ordered collections. These structures are central to everyday JavaScript.

Classes and modules

Class syntax offers a familiar way to define object types. Modules divide programs into reusable files with explicit imports and exports.

Example: compute a value

The code below illustrates function definition, parameters, local variables, a loop, and a return value—concepts previewed by the tour.

// Original teaching example: sum the positive integers up to n
function sumTo(n) {
  let total = 0;
  for (let value = 1; value <= n; value++) {
    total += value;
  }
  return total;
}

sumTo(5); // 15
05 · Putting ideas together

From small constructs to useful programs

Chapter 1 closes its tour with a larger character-frequency histogram program. The example is there to show how real programs combine many features—collections, iteration, functions, formatting, and asynchronous input/output—not to suggest that beginners should already understand every line.

The important lesson is composition: small language features and host APIs work together to solve a concrete task. The book then proceeds from fundamentals toward more advanced abstractions, while later chapters cover browser and Node environments in depth.

06 · Review

Key takeaways

  1. JavaScript is a standardized, evolving language used in many environments.
  2. The runtime supplies environment-specific APIs; browser and Node capabilities differ.
  3. Use an interactive console to test expressions and build intuition.
  4. Variables, values, operators, control flow, functions, objects, classes, and modules form a roadmap for the rest of the book.
  5. Complex programs are compositions of these simpler ideas, and it is normal not to understand every feature in an early overview.
